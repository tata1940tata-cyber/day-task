# DayTask — трекер задач на день

Простое кроссплатформенное приложение (iOS / Android) для ведения списка задач
на текущий день. Реализовано на **Flutter** по техническому заданию
(`ТЗ_ТрекерЗадач.md`), версия 1.0.0 (MVP).

> 🌐 **Онлайн-демо (GitHub Pages):** https://tata1940tata-cyber.github.io/day-task
> — та же сборка, что и на мобильных платформах; данные хранятся в браузере.

## Функции (ТЗ, раздел 5)

| Функция | Реализация |
|---|---|
| FR-01 Список задач на сегодня | Экран «Сегодня»: дата, счётчик «Выполнено X из Y», невыполненные сверху, выполненные — под заголовком «Выполненные (X)» |
| FR-02 Добавление задачи | Поле ввода + кнопка «+» / Enter; валидация 1–200 символов; лимит 100 задач в день; серийный ввод |
| FR-03 Отметка выполнения | Тап по чекбоксу или строке; анимация галочки и зачёркивания; перенос в группу выполненных; обратимо |
| FR-04 Удаление | Свайп влево (≥ 50% ширины) или долгое нажатие с подтверждением; snackbar «Задача удалена · Отменить» (Undo, 5 секунд) |
| FR-05 Сохранение | Hive на устройстве; запись сразу после каждого действия; данные переживают убийство приложения, перезагрузку и обновление |
| FR-06 Анимации | A1–A12 по спецификации ТЗ: появление, галочка, зачёркивание, перенос, удаление, возврат, каскад списка, тема, snackbar/лист, «покачивание» ошибки; поддержка «Уменьшить движение» |
| FR-07 Кроссплатформенность | Одна кодовая база Flutter для iOS и Android; нативное поведение платформ |

## Технический стек

- Flutter 3.x (Dart 3), Material 3, светлая и тёмная темы
- Состояние: Riverpod (`flutter_riverpod`)
- Хранилище: Hive (`hive`, `hive_flutter`), JSON-совместимые записи без codegen
- Локализация: русский и английский (`flutter_localizations`), даты по локали
- Тесты: `flutter_test` (unit + widget)

## Сборка и запуск

Требования: [Flutter SDK](https://docs.flutter.dev/get-started/install) 3.27+
(проверено на 3.47.9 / Dart 3.13), для iOS — macOS с Xcode 15+.

> ⚠️ Размещайте проект в пути **без кириллицы и пробелов** (например,
> `C:\dev\day_task`): Gradle и часть инструментов Flutter (включая
> `flutter analyze`) некорректно работают с не-ASCII путями. При падении
> `flutter analyze` с ошибкой LSP используйте `dart analyze` — он работает.

Платформенные папки `android/` и `ios/` уже включены в проект (сгенерированы
`flutter create` для org `com.daytask`, project `day_task`). Достаточно:

```bash
flutter pub get          # зависимости
flutter run              # запуск на подключённом устройстве/эмуляторе
```

### Android

```bash
flutter build apk --release          # APK для установки вручную
flutter build appbundle --release    # AAB для Google Play
```

### iOS

```bash
flutter build ipa --release          # сборка для TestFlight / App Store
```

## Тесты

```bash
flutter analyze        # статический анализ (или: dart analyze)
flutter test           # unit- и widget-тесты
                       # при нехватке ресурсов машины: flutter test -j 2
```

Проверено на Flutter 3.47.9: `dart analyze` — 0 замечаний, `flutter test` —
42 теста, все зелёные.

Покрываются: модель и JSON-схема, валидация, сортировка/фильтр по дню,
персистентность Hive (включая переоткрытие и повреждённые записи), сценарии
экрана: пустое состояние, добавление, отметка, порядок, удаление свайпом и
через подтверждение, Undo, лимит 100, ошибка хранилища, смена темы,
«Уменьшить движение», локализация, быстрые повторные нажатия (чёт/нечёт).

## Принятые реализационные решения

- Возврат снятой задачи — на исходную позицию по порядку создания (FR-03).
- Undo действует только на последнюю удалённую задачу (FR-04, S3).
- Тап по любой точке карточки (включая чекбокс) переключает статус; чекбокс —
  визуальный элемент, чтобы исключить двойное срабатывание (FR-03).
- Вставка текста длиннее 200 символов обрезается с подсказкой «Максимум 200
  символов».
- При недоступном хранилище приложение стартует в состоянии ошибки с кнопкой
  «Повторить»; при схеме данных новее текущей — режим только для чтения
  (данные не удаляются).
- Свайп-удаление реализовано собственным жестом (см.
  `lib/presentation/today/widgets/task_tile.dart`): карточка уезжает влево,
  гаснет и схлопывается за 250 мс (A6); при недостаточном свайпе возвращается
  за 200 мс (A7), «отскок» ограничен 4 px.
- Перемещение выполненной задачи анимируется как remove + insert в
  `AnimatedList` (A4) с длительностью 300 мс.
